# NRA-Network | DNS Optimizer (God-Mode Edition)

Ultra-fast parallel DNS benchmark and automated network optimizer tool, wrapped in a modern WPF Dark GUI.

## Features
- **Ultra-fast parallel benchmark:** Test multiple DNS providers simultaneously.
- **Anti-NXDOMAIN hijack detection:** Verifies correct response for non-existent domains.
- **Modern Standards:** DoH/DoT/ECS/DNSSEC tagging and filtering.
- **Game Gateways:** TCPing for SEA Game Gateways latency testing.
- **Automated MTU Finder:** Optimal MTU detection using binary search.
- **Advanced Network Optimization:** NIC & TCP/IP Registry Optimizer.
- **Modern WPF Dark GUI:** Clean, user-friendly interface.
- **1-Click Actions:** Apply fastest DNS, Best AdBlock, Best Privacy, and 1-Click Rollback/DHCP reset.

## Requirements
- Windows 10 / Windows 11
- PowerShell 5.1 or PowerShell 7+ (pwsh)
- Administrator privileges (for applying DNS, MTU, and Registry settings)

## Usage
Run `start_benchmark.bat` to launch the modern GUI, or run `GUI.ps1` directly from an Administrator PowerShell console.
